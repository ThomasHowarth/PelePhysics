**********
Mechanisms
**********

The chemical mechanisms distributed with PelePhysics are located in ``${PELE_PHYSICS_HOME}/Mechanisms``. Each mechanism has its own directory, which contains the species thermodynamic and transport data and, for reacting mechanisms, the chemical kinetics, both as input data and as the C++ source code generated by CEPTR (see :ref:`sec:ceptr`). This section describes the content of a mechanism directory, how a mechanism is selected, and lists the mechanisms that are available along with the references recorded for each of them in the repository.

Contents of a mechanism directory
=================================

A typical mechanism directory, for example ``Mechanisms/drm19``, contains the following files:

* ``mechanism.yaml``: the mechanism in the `Cantera <https://cantera.org>`_ YAML format. This is the input file used by CEPTR.
* ``mechanism.inp``, ``therm.dat`` and ``tran.dat``: the kinetics, thermodynamic and transport data in CHEMKIN format, from which ``mechanism.yaml`` was obtained (see :ref:`Converting CHEMKIN files <sec_convertCK>`). These files are not available for every mechanism, and the thermodynamic and transport data are sometimes included in ``mechanism.inp`` directly.
* ``mechanism.H`` and ``mechanism.cpp``: the C++ source code generated by CEPTR, which is compiled into the Pele codes. ``mechanism.H`` defines, among others, the number of elements, species and reactions (``NUM_ELEMENTS``, ``NUM_SPECIES`` and ``NUM_REACTIONS``).
* ``Make.package``: the list of source files for the GNUmake build system.
* ``convert.sh``: a helper script that calls ``Mechanisms/converter.sh`` to regenerate ``mechanism.H`` and ``mechanism.cpp`` from ``mechanism.yaml``.

Some directories contain additional files, such as a ``README`` or the files of the original distribution of the mechanism.

The directories of the reduced mechanisms relying on the quasi-steady state (QSS) assumption (see :ref:`the QSS section <sec_qss>`) have the suffix ``_qss`` and differ slightly:

* ``skeletal.yaml``: the skeletal mechanism to which the QSS assumption is applied.
* ``non_qssa_list.yaml``: the list of the species that are *not* treated as QSS species, i.e. the species that are transported.
* ``qssa.yaml``: the QSS mechanism generated from the two previous files. This is the input file used by CEPTR to generate ``mechanism.H`` and ``mechanism.cpp``.
* ``qssa_input.toml``: the formatting options for the symbolic analytical Jacobian.

There is no ``convert.sh`` in these directories; see :ref:`sec:tutorials` for the procedure to regenerate a QSS mechanism.

For mechanisms with pressure-dependent Arrhenius (PLOG) reactions, the generated code is only valid at the pressure provided to CEPTR, and ``mechanism.H``, ``mechanism.cpp`` and ``Make.package`` are saved in a pressure-specific subdirectory, for example ``Mechanisms/POLIMI2020/1_000atm``.

The ``Mechanisms`` directory itself also contains:

* ``PPHYS_CONSTANTS.H``: a header of constants (e.g. the universal gas constant and the atomic weights), which is part of the build for every mechanism.
* ``converter.sh``: the script called by the ``convert.sh`` of each mechanism.
* ``list_mech``: the list of the ``mechanism.yaml`` files used for the batched generation of the mechanisms with CEPTR. A PLOG pressure (in Pa) can be appended to a line with ``--plog=``.
* ``list_qss_mech``: the equivalent list for the QSS mechanisms. Each line provides ``qssa.yaml``, ``qssa_input.toml``, ``skeletal.yaml`` and ``non_qssa_list.yaml``.

The mechanisms in these two lists can all be regenerated at once, as described in :ref:`sec:ceptr`.

Selecting a mechanism
=====================

The mechanism is selected at compile time. When using GNUmake, this is done by setting the ``Chemistry_Model`` parameter in the ``GNUmakefile`` to the name of the mechanism directory, for example::

    Chemistry_Model = drm19

The source files are then taken from ``${PELE_PHYSICS_HOME}/Mechanisms/$(Chemistry_Model)``.

The ``Null`` model
------------------

The ``Null`` directory does not contain a chemical mechanism, and only provides hand-written ``mechanism.H`` and ``mechanism.cpp`` files for a single inert species (named ``AIR``) and no reactions. It must be used when the ``GammaLaw`` EOS is selected (see :ref:`sec:eos`). When the ``Manifold`` EOS is used, the number of species of the ``Null`` model is ``1 + MANIFOLD_DIM`` and the additional species are named ``X1``, ``X2``, etc.

Available mechanisms
====================

The tables below list all the mechanisms available in the ``Mechanisms`` directory. The number of species and reactions are those found in ``mechanism.H``. The descriptions and references are those recorded in the repository, either in the ``README`` of the mechanism or in the header of its ``mechanism.yaml`` or ``mechanism.inp`` file; the reader is referred to these files for more details, in particular regarding the range of validity of each mechanism. When no source could be found in these files, the reference is listed as not recorded.
